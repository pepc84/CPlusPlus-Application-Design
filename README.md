# CPlusPlus-Application-Design
My C++ Application Design class projects and assignments.

## Module 08: Input Validation

I added input validation to my application.

- getPositiveNumber() prevents invalid, zero, and negative numbers.
- getName() prevents empty names.
- add() prevents duplicate record IDs.

The application displays an error message when invalid input is entered and allows the user to try again.

## Module 09: AI Integration

I propose adding an AI-powered search feature.

1. What it does: Allows users to search for records using normal sentences instead of exact IDs.
2. Data needed: Record IDs and names.
3. What the user sees: The user enters a search request and sees matching records.
4. Where AI fits: The application sends the request and record data to an AI model, receives the result, validates it, and displays it.

A mock version can simulate this feature without using a real AI service.
